# PathSnap Evaluator Interface (Laptop 2)

The dashboard lives in `src/phase8_ui/` (HTML + Leaflet, no build step).

- Served by the backend at `http://<LAPTOP1_IP>:8000/ui/`.
- Or standalone: `python -m http.server 5500 --directory src\phase8_ui`, then open `http://localhost:5500/?api=http://<LAPTOP1_IP>:8000`.

See `docs/DEMO_GUIDE.md`.
